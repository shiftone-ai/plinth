隐私政策

Plinth 是 Shift One 提供的 Mac、iPhone 和 iPad 展示应用。本政策说明应用及支持邮箱如何处理数据。

设备上的数据

起始 URL 和显示设置保存在应用的本地存储中。管理员密码以加盐后的验证值保存在设备的 Keychain 中。生物识别使用操作系统的功能，Plinth 不接收生物识别数据。

所选界面语言也保存在设备上。在 Mac 上删除应用不会清除 Application Support 中的设置或 UserDefaults 中的语言设置。在 iPhone 或 iPad 上卸载应用会删除应用的本地存储。Keychain 项目在卸载后仍可能保留。更改管理员密码会覆盖原有的验证值。如需了解如何清除设备上的数据，请联系支持人员。

应用会将状态变化和错误代码等有限的运行记录写入设备系统日志。记录不包含密码、完整展示 URL 或网页内容。日志保留时间由操作系统管理。

展示网站

Plinth 加载管理员指定的网站。该网站及其嵌入的服务可能收到网络请求，并依照各自的政策处理访客数据。Plinth 不控制这些处理方式。

应用使用临时 WebKit 数据存储。“新浏览会话”在重新创建展示画面时使用新的存储。“保留 Cookie 和网站数据”在应用运行期间重复使用同一存储。应用运行结束时会丢弃该存储。

发送给 Shift One 的数据

应用不会向 Shift One 发送展示设置、凭据、运行记录或分析数据。这些页面托管于 GitHub Pages；打开页面时，托管方会收到提供页面所需的常规连接信息。

如果您发送支持邮件，我们会使用邮件地址和您提供的信息回复。请勿发送密码或非公开的展示内容。

支持邮件在回复后仍可能保留。我们尚未核实邮箱和备份的保留设置，因此目前无法说明最长保留期限。如需删除，请使用咨询时的邮箱地址发送邮件至 contact@shiftone.ai。我们会确认可删除的范围，并告知处理结果。

联系

如有隐私问题或删除请求，请联系 contact@shiftone.ai。
