개인정보 처리방침

Plinth는 Shift One이 제공하는 Mac, iPhone, iPad용 전시 앱입니다. 이 문서는 앱과 지원 문의에서 처리하는 데이터를 설명합니다.

기기에 저장되는 데이터

시작 URL과 화면 설정은 앱의 로컬 저장소에 보관됩니다. 관리자 비밀번호는 솔트를 더한 검증 값으로 기기의 Keychain에 저장됩니다. 생체 인증은 운영체제의 기능을 사용하며 Plinth는 생체 정보를 받지 않습니다.

선택한 표시 언어도 기기에 저장됩니다. 앱을 삭제하면 앱 저장소의 데이터도 삭제됩니다. Keychain 항목은 앱을 삭제한 뒤에도 남을 수 있습니다. 관리자 비밀번호를 변경하면 기존 검증 값을 덮어씁니다.

상태 변경과 오류 코드 등 제한적인 작동 기록을 기기의 시스템 로그에 남깁니다. 비밀번호, 전시 URL 전체, 페이지 내용은 기록하지 않습니다. 로그 보관 기간은 운영체제가 관리합니다.

전시 웹사이트

Plinth는 관리자가 지정한 웹사이트를 불러옵니다. 해당 사이트와 포함된 서비스는 네트워크 요청을 받고 각자의 정책에 따라 방문자 데이터를 처리할 수 있습니다. Plinth는 이를 관리하지 않습니다.

앱은 임시 WebKit 데이터 저장소를 사용합니다. “새 탐색 세션”은 전시 화면을 다시 만들 때 새 저장소를 시작합니다. “쿠키 및 사이트 데이터 유지”는 앱이 실행되는 동안 같은 저장소를 재사용합니다. 앱 실행이 끝나면 저장소를 폐기합니다.

Shift One에 전달되는 데이터

앱은 전시 설정, 인증 정보, 작동 기록 또는 분석 데이터를 Shift One에 보내지 않습니다. 이 안내 페이지는 GitHub Pages에서 호스팅하며, 페이지를 열면 서비스에 필요한 일반적인 접속 정보가 전달됩니다.

지원 이메일을 보내면 답변을 위해 이메일 주소와 제공한 정보를 사용합니다. 비밀번호나 비공개 전시 내용은 보내지 마세요.

지원 이메일은 마지막 답변 후 최대 12개월 보관한 뒤 삭제합니다. 더 일찍 삭제를 요청하려면 contact@shiftone.ai로 연락해 주세요. 같은 이메일 주소에서 보낸 요청인지 확인하고 30일 이내에 삭제합니다.
