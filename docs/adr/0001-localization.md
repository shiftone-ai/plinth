# ADR 0001: 管理画面の翻訳

## 決定

String Catalogの原文と未翻訳時の表示を英語にする．日本語・韓国語・中国語の簡体字を訳として持ち，Mac・iPadのアプリ本体にen・ja・ko・zh-Hansを宣言する．OSの言語を既定とし，管理画面内の選択はその端末の利用者設定として別に保存する．対応していない言語では英語を表示する．

## 理由

原文を英語にすると，訳が欠けても読める文が残る．管理画面・解除画面・停止画面はアプリが所有するが，展示するWebページは所有しない．そのためWebの言語には手を加えない．

Swift packageの文言はアプリ本体から検索すると訳が見つからないため，`KioskLocalization` のresource bundleを指定して読む．Presenterは表示用の英語キーだけを返し，翻訳はViewが行う．Macのスクリプトで作る.appには，ビルド結果のresource bundleをすべて同梱する．

繁体字中国語は今回の対象から外す．この言語を追加するときは，catalog・アプリの言語宣言・画面内の選択と実画面の検証を同じ変更で行う．

## 検証

`devenv test` で訳の欠落と未登録キーを検出し，SwiftLintでUIソースの日本語リテラルを検出する．Macの二つのビルド経路とiPadで表示・入力・保存・展示・解除を操作して確かめる．検証結果はPRに記録する．
