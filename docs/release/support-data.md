# サポートメールの取扱い

`contact@shiftone.ai` の問い合わせと削除依頼に適用する予定の運用手順．グループと配信先のメール，複製の削除条件を確認して運用を始めるまでは，以下の期限を公開ページで保証しない．

1. サポートに届いたメールは，返信と問題の調査に必要な範囲で扱う．パスワードや非公開の展示内容が届いた場合は，返信で再送を求めず，不要な添付を削除する．
2. 最後の返信から12か月以内に，問い合わせのメールと添付を受信箱，送信済み，保管先から削除する．月に一度，期限を過ぎたスレッドを確認する．
3. 早期削除の依頼には，元のメールアドレスからの依頼であることを確認し，30日以内に対象スレッドと添付を削除して完了を返信する．別のアドレスからの依頼は，元のアドレスでの確認を求める．
4. バックアップなど通常のメール操作で削除できない複製がある場合は，公開文書の期限を保証できるか運用担当が確認し，必要なら公開文書を訂正する．

利用者によると，`contact@shiftone.ai` は問い合わせグループに届くドメインエイリアス．管理画面には，対象グループの直接メンバー1人・オーナー1人と表示されている．Google グループの会話履歴はオフ．外部からの投稿は許可されている．受信者のGmailで別名宛ての既存メールを検索できたため，過去の配信実績はある．グループには保留中のメッセージが1件ある．組織のGmail設定はメールとチャットを自動削除しない．Google VaultにはGmail・グループのデフォルト保持ルール，カスタム保持ルール，ドメイン・ユーザー・グループの保留がない．設定の変更はしていない．この結果から，現在の設定だけで12か月後にメールが消えるとは言えない．

試験メールを `contact@shiftone.ai` に送信し，送信済みへの記録と受信側の画面で同じ件名・本文を確認した．受信側のメールボックス，送信済みメール，保留中のメッセージ，通常操作で削除できない複製の保存・削除範囲は未確認．12か月・30日の手順を守るには，対象と削除方法を確認して運用する必要がある．組織全体の自動削除は他のメールにも影響するため，このIssueの作業として変更しない．適用と検証の後に4言語の公開ポリシーへ期限を反映する．
