# App Store画像案

## 採用案

- ヘッダ: [`app-store-header.png`](app-store-header.png)（3840×1646）．展示空間にiPadと外部ディスプレイを配置したイメージ画像．実機撮影ではない．
- iPhone 6.9インチ: [`connected-iphone69/`](connected-iphone69/)の`{en,ja,ko,zh-Hans}-{00,01,02}.png`（各1320×2868）．各言語で00→01→02の順に並べる．3枚を並べると背景がつながる．

## 画像の内容

1. 展示中のFlux．
2. 閲覧先の許可リストを含む管理画面．
3. 次の展示作品Drift．

FluxとDriftの画面はiPhone Simulatorでアプリを操作して撮影した．管理画面もSimulatorの実画面を使った．背景，見出し，端末枠，ヘッダの展示空間は販促用の合成表現．展示サンプル内の操作ラベルは英語で，アプリの管理画面は各言語に切り替えている．

[`connected-iphone69/render.html`](connected-iphone69/render.html)は3枚を一度に描く原稿．既存のiPad・Mac画像には変更を加えていない．
