# 配布物のライセンス表示

## 現在の棚卸し

`main` の `0757c9b` を基にしたソースを確認した．公開候補の配布物との最終照合は残る．

| 対象 | 確認結果 | 表示 |
| --- | --- | --- |
| Swift Package | `swift package dump-package` の `dependencies` は空 | 外部Packageの表示対象なし |
| アプリで読み込むモジュール | プロジェクト内モジュールとAppleのシステムフレームワーク | 外部ライブラリの表示対象なし |
| 同梱素材 | アプリアイコンは `scripts/create-app-icon.swift` から生成．その他の配布用画像・フォント・音声・動画はソースにない | 外部素材の表示対象なし |
| テスト素材 | `Tests/KioskNativeTests/Fixtures/video.mp4` はテストtargetのresource | アプリへの同梱対象外 |
| 転用コード・ライセンス文書 | `Sources/` と `Resources/` に転用元や外部ライセンスを示すファイルは見つからない | 現時点の表示対象なし |

管理画面の「ライセンス」は，現行の棚卸しに対応して対象がない旨を表示する．Appleのシステムフレームワークの利用を，外部ライブラリのライセンス表示として扱わない．

## 同梱物を追加するとき

1. 追加するPackage，framework，素材，転用コードの取得元・版・著作権者・ライセンス本文と表示条件を確認する．
2. 配布物に実際に含まれるか，Mac版とiPhone／iPad版の両方で確認する．開発・テスト専用の依存物は分ける．
3. 表示が必要なものは，原文を変更せずにアプリへ同梱し，「ライセンス」画面から名称・著作権表示・本文・必要なクレジットを読めるようにする．
4. 画面を両プラットフォームで操作し，配布物の内容と表示を照合する．公開準備表も更新する．

配布候補での棚卸しと，実際の画面・配布物の照合が終わるまで，この結果を候補ビルドの最終判定には使わない．
